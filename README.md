# Juice Shop Login Clone

A basic login page modeled on the [OWASP Juice Shop](https://owasp.org/www-project-juice-shop/) login screen, built for CSCE 477.

## What it does

- Fairly realistic & basic clone of the OWASP juice shop login form.
- Contains client-side input validations on client inputs.
- Contains server sided client input validations.

## How to run

Requirements: [Node.js](https://nodejs.org/) 18 or newer.

```bash
cd juice-shop-login-clone
npm start
```

Then open <http://localhost:3000>. To use a different port, run `PORT=<your port> npm start`.

**Demo login:** `admin@juice-sh.op` / `supersecretpassword`
